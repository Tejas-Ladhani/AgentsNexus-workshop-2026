# Module 8 - Readiness Assessment (Deferred)

The installed MCP Scanner readiness analyzer checks non-standard top-level fields such as `timeout`, `maxRetries`, `errorSchema`, and `rateLimit`. Standard FastMCP `tools/list` responses do not expose those fields, so a remote scan produces the same missing-timeout result for every tool and is not useful for this workshop.

Skip this module for now. Continue with [09-llm-analysis.md](09-llm-analysis.md) for live semantic analysis.
